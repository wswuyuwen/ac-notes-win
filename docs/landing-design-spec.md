# 动森版随手记落地页设计规范

> 参考源站：[WaterGrug](https://watergrug.pages.dev/)  
> 应用基础：ACNotes 动森版随手记（macOS / Windows）

## 1. 源站设计特征

WaterGrug 的视觉核心不是“可爱卡通”，而是纸、墨水、手账本这套完整的设计语言。先把它拆开，再转译给动森版随手记。

### 1.1 手账本质感

- 暖米色纸张作为页面底色，卡片用更浅的纸色，形成“纸上的纸”的层次。
- 页面整体覆盖低透明度颗粒噪点，模拟纸张纤维。
- 深棕墨色负责文字、描边和图标，不用纯黑制造生硬感。
- 卡片、按钮、图标框都使用不规则圆角，像是手绘时没有画得完全整齐。

### 1.2 墨线手绘

- 所有边框统一为 2.5px 左右的深色描边，圆角不追求平滑，允许轻微“歪”。
- 卡片轻微旋转，奇数/偶数交替倾斜 0.4deg 左右，制造手贴便签的随意感。
- 图标统一用 2px 圆头描边线条，不用精细线性图标，也不用复杂渐变。
- 标题下划线、列表勾选、按钮加号等装饰用小段手绘 SVG 路径。

### 1.3 克制配色

- 主色：纸色背景 + 深棕墨色。
- 强调色：只保留一个主强调色（源站是水蓝色）和它的浅色容器色。
- 阴影：使用带透明度的深棕色硬阴影，而不是大面积柔光。

### 1.4 产品优先

- Hero 直接展示真实 App 界面截图，不靠抽象插画撑版面。
- 功能以“一个功能一句话”的卡片表达，信息密度适中。
- 页面包含功能、截图、设备端体验、价格/版本、隐私、FAQ，转化路径清晰。
- 文案温和、具体，避免制造焦虑。

### 1.5 交互手感

- 按钮有手绘纸片感：默认 3px 硬阴影，hover 轻微上浮，按下时下沉并消除阴影。
- 卡片 hover 轻浮起并加深硬阴影，不改边框颜色；导航 hover 只做变色和轻微位移。
- 文字悬停参考 oiloil.org：标题和链接悬停时在文字下方铺一段 `--accent-soft` 高亮，过渡使用 `cubic-bezier(0.19, 1, 0.22, 1)`，不改变布局。
- 光标参考 oiloil.org：桌面精细指针下隐藏系统光标，使用墨色箭头跟随；悬停链接、按钮或文字高亮目标时切换为主题色圆点。
- 支持 prefers-reduced-motion，动画全部可关闭。

## 2. 动森版转译原则

动森随手记不直接复制 WaterGrug 的水蓝，而是保留它的“纸与墨水”骨架，换成 ACNotes 的奶油、木色、森林绿 / 海水蓝视觉体系。

双主题色以项目实际主题切换色为准：sea 主题使用 `#98D2E3`，tree 主题使用 `#62B98B`。两个色值来自 `ac-notes-mac/Sources/ACNotes/Theme.swift`，并在 `ac-notes-mac/Sources/ACNotes/NotebookView.swift` 与 `ac-notes-win/src/AcNotes.Windows/MainWindow.cs` 中随主题切换联动，落地页也统一采用这两套值。

### 2.1 保留

- 暖纸底、深墨描边、颗粒噪点。
- 手绘不规则圆角、硬阴影、卡片轻微旋转。
- 真实产品截图优先，功能卡片简洁克制。
- 温和、治愈、不打扰的产品语气。

### 2.2 替换

- 水蓝强调色 → tree 森林绿 `#62B98B`，sea 海水蓝 `#98D2E3` 作为双主题辅助。
- 水滴 Logo → 手绘笔记本、叶子或猫爪图标。
- iPhone / Apple Watch 截图 → MacBook 刘海条、展开面板、sea / tree 双主题截图。
- “喝水目标”叙事 → “随手记录、悬浮即写、自动收起”叙事。

### 2.3 禁止

- 不用任天堂官方素材；所有动森风格元素使用原创 CSS / SVG 或项目已有原创素材。
- 不做大面积渐变光球、霓虹色、玻璃拟态或纯扁平营销页。
- 不为“可爱”牺牲可读性：正文不小于 15px，正文和背景对比度要足够。
- 不使用五颜六色拼贴；整体仍是纸色 + 木色 + tree/sea 双主题强调。

## 3. 设计 Tokens

建议直接用 CSS 变量落地，后续页面统一引用。

### 3.1 浅色模式

```css
:root {
  --bg: #F5F0E8;            /* 页面纸张 */
  --paper: #FAF7F2;         /* 卡片、面板 */
  --paper-deep: #F7F3DF;    /* 编辑区、价格贴纸 */
  --ink: #2A2118;           /* 墨色描边 / 标题 */
  --ink-soft: #6B5B45;      /* 次级正文 */
  --wood: #725D42;          /* 木色辅助 */
  --tree: #62B98B;          /* 主强调：tree 森林绿 */
  --tree-soft: rgba(98, 185, 139, 0.18); /* 图标框、选中浅底 */
  --sea: #98D2E3;           /* sea 主题海水蓝 */
  --sea-soft: rgba(152, 210, 227, 0.22); /* sea 浅底 */
  --sand: #C4B89E;          /* 低优先级文字 / 装饰点 */
  --shadow: rgba(42, 33, 24, 0.18);
  --shadow-strong: rgba(42, 33, 24, 0.28);
}
```

### 3.2 字体

```css
--font-body: "ZCOOL KuaiLe", "Hiragino Maru Gothic ProN", "PingFang SC",
  "Microsoft YaHei", sans-serif;
--font-num: "Caveat", "ZCOOL KuaiLe", cursive;
```

- 正文：17px，行高 1.75。
- H1：clamp(34px, 5.4vw, 56px)，行高 1.28。
- H2：clamp(26px, 3.6vw, 38px)，行高 1.35。
- H3：20px。
- 卡片正文：15px。
- 小字：14px。
- 数字、价格、装饰性手写字：Caveat。
- letter-spacing 为 0，不压字距。

## 4. 页面结构

### 4.1 导航

- 固定吸顶，高度 64px。
- 背景为不透明纸张色，底部 2.5px 墨线。不要使用 backdrop-filter，避免 Chromium 在频繁展开/收起内容时把吸顶层重绘成黑色块。
- 左侧：手绘叶子 / 笔记本 Logo + 动森随手记。
- 右侧：功能、演示、主题、FAQ，不重复放下载入口；下载集中在 Hero 的双版本下载区。
- 移动端只保留 Logo、主题切换和必要入口。

### 4.2 Hero

- 两栏：左侧文案，右侧真实面板截图。
- 顶部 badge：macOS · Windows · 本地存储。
- H1 用“随手记”做墨线高亮，例如：把灵感，随手记在屏幕顶部。
- 副标题：鼠标滑过顶部，奶油色笔记本展开，记完自动收起。不打断当前应用。
- 主 CTA：Mac 版下载、Windows 版下载，直接链接最新安装包；次 CTA：看看功能。
- CTA 下方放一句安心文案：Mac 安装包 / Windows 免装版 · 无需账号 · 数据只存在本机。
- 移动端把产品截图放到文案上方。

### 4.3 功能区

用 4 到 8 张手绘描边卡片，每张一个核心能力：

- 悬浮即记：鼠标滑过屏幕顶部，面板展开即写。
- 所见即所得：Markdown 实时渲染，不用切到编辑器。
- 输入即保存：没有保存按钮，自动落盘双副本。
- 多标签随手记：工作、生活、灵感分开，点击即切换。
- 双主题：sea 海之主题 / tree 树之主题。
- 文件架：拖文件到刘海暂存，拖出完成搬运。
- 粘贴图片：截图后直接粘贴，自动存库并内嵌显示。
- 不打扰：按 Esc 快速收起，面板不会抢焦点。

### 4.4 真实演示区

- 必须使用真实录屏或真实截图，不画示意占位图。
- 可展示：收起状态刘海条 → 展开状态面板 → 输入 → 移开自动收起。
- 演示卡需要有真实交互手感：鼠标滑过展开面板，移开自动收缩；键盘或触屏聚焦时也可展开。
- 演示卡使用纸色背景、2.5px 墨线、硬阴影。
- 演示面板产品图跟随顶部主题切换：tree 显示森林主题截图，sea 显示海之主题截图。

### 4.5 双主题区

- 两张真实面板截图：sea 和 tree。
- 每张截图下方写主题名和一句说明。
- 卡片内不要堆叠多余装饰。

### 4.6 细节区

- 用真实截图展示删除确认弹窗、文件架等小交互。
- 文案突出“认真问你一句”，而不是罗列功能。
- 删除确认弹窗同样提供 sea / tree 两版真实截图，并跟随顶部主题切换。

### 4.7 隐私与 FAQ

- 隐私区用三张小卡：纯本地存储、无账号、无追踪。
- FAQ 使用原生 `details` / `summary` 纸色卡片，加号用 Caveat 手写体，展开后旋转 45 度。
- 区块标题不保留 FEATURES、FAQ 等英文 tag，直接以 H2 和副标题开始。

### 4.8 页脚

- 顶部 2.5px 墨线。
- 页脚上部提供社交入口列表：小红书、抖音、GitHub、邮箱。
- 社交入口采用编号、图标、名称/地址、右上箭头四段式链接卡，桌面 4 列、平板 2 列、窄屏 1 列。
- 链接卡使用纸色背景、2.5px 墨线、硬阴影，hover 时背景变主题浅色、阴影加深并轻微上移。
- 保留项目名、GitHub、版本说明。
- 补充非商用、非任天堂官方产品声明。

## 5. 组件规范

### 5.1 手绘圆角

```css
.sk-a { border-radius: 255px 15px 225px 15px / 15px 225px 15px 255px; }
.sk-b { border-radius: 15px 225px 15px 255px / 255px 15px 225px 15px; }
.sk-c { border-radius: 225px 15px 255px 15px / 15px 255px 15px 225px; }
.sk-card { border-radius: 18px 22px 20px 24px / 22px 18px 24px 20px; }
```

### 5.2 按钮

- 背景 --paper 或 --tree。
- 边框 2.5px --ink。
- 圆角使用手绘不规则值。
- 阴影：3px 3px 0 var(--ink)。
- hover：translate(-1px, -1px)，阴影 4px 4px。
- active：translate(2px, 2px)，阴影 0 0 0。

### 5.3 卡片

- 背景 --paper，边框 2.5px --ink。
- 阴影 4px 4px 0 var(--shadow)。
- 奇数卡片 rotate(-0.4deg)，偶数卡片 rotate(0.4deg)。
- 图标框 52x52，背景 --tree-soft，2.5px 墨线，手绘圆角。

### 5.4 图标

- 全部使用原创 SVG 或项目已有 lucide 图标。
- 线条 2px，stroke-linecap round，stroke-linejoin round。
- 图标主色 --ink，容器色 --tree-soft。
- 不用彩色渐变图标。

### 5.5 截图框

- 真实截图外层统一 3px --ink 边框。
- 面板截图可用更接近方形的手绘圆角。
- 刘海条截图使用胶囊圆角。
- 阴影统一 4px 5px 0 var(--shadow)。

## 6. 纹理与装饰

### 6.1 纸张噪点

不建议使用 fixed 全屏 SVG feTurbulence 噪点层。该滤镜会触发整页 GPU 合成，频繁布局变化时容易在部分 Chromium 设备上出现黑色区域；如要保留纸感，使用 CSS 背景重复图或纯色纸张即可。

### 6.2 章节标题装饰

- H2 下方使用一条重复的短手绘波浪线。
- 颜色用 --tree 或 --sea。
- 区块顶部不添加英文小标签，避免标题层级被 tag 打断。
- 不要加粗、不要用纯直线代替。

### 6.3 背景

- 允许极淡的波点或树叶轮廓，但不使用离散光球、大面积渐变光晕。
- 主背景保持纸张色，视觉焦点始终是产品截图和内容。

## 7. 动效

- Hero 截图可做 6s 上下浮动，位移不超过 8px。
- 卡片 hover 轻微抬升或旋转。
- 按钮有物理按压感。
- FAQ 展开收起完全交给浏览器原生 `details` 语义处理，不手写按钮状态、不控制 `visibility` / `opacity`，不叠加绝对定位遮罩。
- 原生 `details` 在连续点击时由浏览器内部状态机管理，避免自绘内容层在快速切换时出现黑色重绘块。
- 所有动画在 prefers-reduced-motion: reduce 下关闭。

## 8. 响应式与无障碍

- 桌面最大宽度 1080px，左右 padding 24px。
- Hero 在 860px 以下单列，截图置顶。
- 功能卡 repeat(auto-fit, minmax(250px, 1fr))。
- 截图条在 900px 以下横向滚动，支持 scroll-snap。
- 正文不小于 15px；小字不小于 12px。
- 焦点态使用 3px --tree outline，sea 主题下使用 3px --sea，偏移 2px。
- 图标按钮必须有 aria-label 或可读文本。
- 颜色对比度按正文、次级正文分别检查。

## 9. 文案语气

- 短句，具体，先给结果再解释。
- 避免“颠覆、高效、赋能”等营销词。
- 用“不打断、不打扰、不抢焦点”表达产品温和感。
- 示例 H1：把灵感，随手记在屏幕顶部。
- 示例 sub：鼠标滑过屏幕顶部，奶油色笔记本展开；记完移开，自动收进刘海。不打断当前应用。
- 示例 CTA：免费下载、看看功能。
- 示例 footnote：无需账号 · 数据只存在本机。

## 10. 验收清单

- 页面第一眼是“纸与墨水的手账本”，不是抽象插画或营销卡片。
- Hero 展示真实 ACNotes 面板截图。
- 主强调色使用 tree `#62B98B`，sea `#98D2E3` 作为双主题辅助。
- 边框统一为墨色手绘线，阴影统一为深棕硬阴影。
- 卡片有轻微旋转，但不影响阅读。
- 按钮 hover / active 有纸片按压手感。
- 移动端无横向溢出，按钮和文字不被裁切。
- prefers-reduced-motion 可关闭所有动画。
- 未使用任天堂官方素材，仅保留风格化原创视觉。
- 页面保留非商用与非官方产品声明。
